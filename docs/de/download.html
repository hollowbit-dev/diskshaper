macOS 11 Big Sur oder neuer. Versionen für Apple Silicon und Intel.

Apple Silicon (M1 und neuer) Intel-Mac

Windows

Windows 10 oder 11, 64 Bit.

Für Windows laden

Erster Start

Mac

  1. Öffne die geladene .dmg und zieh Diskshaper in Programme.
  2. Beim ersten Mal: Rechtsklick auf Diskshaper, Öffnen wählen, dann nochmal Öffnen.
  3. Drück auf Scannen. Fragt macOS nach Zugriff auf Schreibtisch, Dokumente oder Downloads, erlaube es, damit Diskshaper dort große Dateien findet.

Windows

  1. Starte das Installationsprogramm.
  2. Erscheint SmartScreen, klicke auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.
  3. Öffne Diskshaper über das Startmenü und drück auf Scannen.

Die Warnungen erscheinen, weil Diskshaper nicht mit einem kostenpflichtigen Zertifikat signiert ist. Es ist kostenlos, Open Source und stellt keine Internetverbindung her.
