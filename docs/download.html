First launch

Mac

  1. Open the downloaded .dmg and drag Diskshaper to Applications.
  2. The first time, right-click Diskshaper and choose Open, then Open again.
  3. Press Scan. If macOS asks to access Desktop, Documents or Downloads, allow it so Diskshaper can find big files there.

Windows

  1. Run the installer.
  2. If SmartScreen appears, click “More info”, then “Run anyway”.
  3. Open Diskshaper from the Start menu and press Scan.

The warnings appear because Diskshaper is not signed with a paid certificate. It is free and open source, so anyone can read every line of its code.
