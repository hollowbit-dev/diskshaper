How to delete CrossOver bottles you no longer need

Every CrossOver bottle is a small Windows install, about 300 MB empty and often several gigabytes once runtimes are added. Bottles stay after you delete the game inside. In CrossOver, select the bottle and choose Delete Bottle. Diskshaper finds bottles with no game left inside and lists them as Safe.

Updated 11 November 2026 · Hollowbit Studio

Download for Mac Download for Windows

Step by step

  1. Quit CrossOverSo no bottle is in use.
  2. Download Diskshaper and press Scan this MacIt reads ~/Library/Application Support/CrossOver/Bottles.
  3. Open GamingEmpty CrossOver bottles shows bottles with only Windows and runtimes inside. CrossOver bottles shows the rest, with the games each one holds.
  4. Move empty bottles to the TrashIf you change your mind, put the bottle back from the Trash and CrossOver finds it again.

How Diskshaper knows a bottle is empty

It looks inside each bottle’s Program Files folders and its Steam library. If there is nothing but Windows components and runtimes like .NET, DirectX or Edge WebView2, no game is left.

The manual way

Open CrossOver, select a bottle in the sidebar, and use Bottle, Delete Bottle (or right-click it). You can see each bottle’s files by right-clicking it and choosing Open C: Drive.

Saves inside bottles

Windows games often save to the bottle’s users folder. Before deleting a bottle with a game you might play again, copy drive_c/users somewhere safe.

Questions

How much space does an empty bottle use?

About 300 MB for a fresh bottle, and more once .NET or other runtimes were installed. Five empty bottles can easily take 3 GB.

Will deleting a bottle remove CrossOver?

No. Only that bottle. CrossOver and your other bottles stay.

Does this work for Whisky or Wine?

Diskshaper reads CrossOver bottles today. Other Wine setups may come later.
