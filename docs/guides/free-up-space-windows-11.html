How to free up disk space on Windows 11

Start with Windows’ own Cleanup recommendations in Settings, System, Storage: it clears temporary files and old Windows updates. Then scan with Diskshaper for what Windows does not know about: shader caches, Steam and Epic leftovers, Premiere and Resolve caches, old installers and duplicate photos. Everything goes to the Recycle Bin, so you can undo it.

Updated 11 November 2026 · Hollowbit Studio

Download for Mac Download for Windows

Step by step

  1. Run Windows’ cleanup firstSettings, System, Storage, Cleanup recommendations. Tick temporary files and old updates.
  2. Download Diskshaper for WindowsFree, no account. If SmartScreen appears, choose More info, Run anyway.
  3. Press Scan this PCYou get Everyone, Gaming and Video editing groups with sizes.
  4. Move what is Safe to the Recycle BinThen empty the Recycle Bin to get the space back.

What Windows cleans and what it misses

Windows cleans its own temporary files, update leftovers and the DirectX shader cache. It does not know about Steam’s per-game shader caches, folders left by uninstalled games, editing app caches, or the installers piling up in Downloads.

Turn on Storage Sense

Settings, System, Storage, Storage Sense can empty the Recycle Bin and clear Downloads on a schedule. Be careful with the Downloads option if you keep files there.

Big wins people forget

Games you have not played in months (uninstall from the launcher, reinstall any time), old phone backups and video exports. Diskshaper lists games with the last time you played.

Questions

Is it safe to delete the Windows temp folder?

Yes, for files not in use. Windows skips the ones that are. Diskshaper lists %TEMP% under App caches.

Should I delete the WinSxS folder?

No. Never delete it by hand. Use Windows’ cleanup, which removes old components safely.

Is Diskshaper safe for Windows?

It never touches Windows system folders, and it moves files to the Recycle Bin instead of deleting them.
