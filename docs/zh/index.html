给玩家

游戏是大多数磁盘上最占空间的东西，卸载后还会留下一堆杂物。

Diskshaper 直接读取 Steam、Epic、Heroic 和 CrossOver 的数据，所以知道哪些文件夹还属于某个游戏，哪些是被遗留下来的。

  • 着色器缓存游戏和显卡驱动会自动重新生成的图形数据。
  • 已卸载游戏的残留Steam 和 Epic 卸载游戏后留下的文件夹。
  • 很久没玩的游戏显示上次游玩时间，并提供在启动器中卸载的按钮。
  • 空的 CrossOver 容器Mac 上里面的游戏早已删除的 Windows 环境。

给视频剪辑者

剪辑软件会悄悄存下几十 GB 的缓存、预览和代理文件。

Diskshaper 会在软件目录和项目旁边找到它们，并告诉你哪些软件会自动重新生成。

  • Premiere、After Effects 和 Resolve 缓存媒体缓存、峰值文件、渲染缓存和代理文件。
  • 项目旁边的渲染预览Premiere 和 Final Cut 存在项目文件旁边的预览文件夹。
  • 重复的素材同一个片段复制到了三个地方。保留最早的那份。
  • 旧的导出文件六个月没动过的大型渲染文件，每个都有缩略图。

日常杂物：只用过一次的安装包、保存了两次的同一张照片，还有旧笔记本上那个 40 GB 的备份压缩包。

清楚的标签

“安全”表示软件会重新生成，或者你可以重新下载。“先检查”表示只有你知道，所以永远不会替你勾选。

一律进废纸篓

什么都不会被直接删除。所有内容都进废纸篓或回收站，清空之前都能放回去。

从不碰系统文件

Diskshaper 只查看你自己的文件夹、应用缓存和游戏库，不会动 macOS 或 Windows。

点击前只读不写

常见问题

Diskshaper 真的免费吗？

是的。没有付费版、没有试用期、没有广告。它是开源的，由 Hollowbit Studio 制作，他们也做了 Fileshaper、Captionshaper 和 Writeshaper。

它会删掉我需要的东西吗？

不会自作主张。只有你勾选的项目才会被处理，而且是移到废纸篓或回收站，不会直接删除。标为“先检查”的项目永远不会替你勾选。

它会上传我的文件或追踪我吗？

不会。扫描在你的电脑上进行，不会发送任何关于你或你文件的信息。应用唯一的联网是每天检查一次新版本，可以关闭。没有任何统计。

为什么清理后空间还没释放？

因为所有内容都先进废纸篓，方便撤销。确认无误后清空废纸篓或回收站，空间就回来了。

支持哪些电脑？

macOS 11 Big Sur 或更高版本（Apple Silicon 和 Intel），以及 Windows 10 和 11（64 位）。
