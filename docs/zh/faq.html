问题与解答

Diskshaper 真的免费吗？

是的。没有付费版、没有试用期、没有广告。它是开源的，由 Hollowbit Studio 制作，他们也做了 Fileshaper 和 Captionshaper。

它会删掉我需要的东西吗？

不会自作主张。只有你勾选的项目才会被处理，而且是移到废纸篓或回收站，不会直接删除。标为“先检查”的项目永远不会替你勾选。

它会上传我的文件或追踪我吗？

不会。扫描在你的电脑上进行，应用完全不联网，也没有任何统计。

为什么清理后空间还没释放？

因为所有内容都先进废纸篓，方便撤销。确认无误后清空废纸篓或回收站，空间就回来了。

支持哪些电脑？

macOS 11 Big Sur 或更高版本（Apple Silicon 和 Intel），以及 Windows 10 和 11（64 位）。

它和 CleanMyMac、CCleaner、DaisyDisk 有什么不同？

它们都是好工具，但大部分清理功能需要订阅或购买许可，DaisyDisk 只显示大小，不告诉你什么是安全的。Diskshaper 免费，用简单的话解释每一组，而且懂游戏和剪辑软件，这正是通用清理工具常常忽略的。

清理着色器缓存会影响游戏吗？

不会。着色器缓存会在下次游玩时重新生成。最初几分钟可能会有一点卡顿，之后就恢复正常。

删除游戏的残留文件夹会删掉存档吗？

大多数游戏把存档放在“文档”、AppData 或 Steam 云中，而不是游戏文件夹里。只有当 Steam 或 Epic 不再列出该游戏时，Diskshaper 才会把文件夹标为残留。如果某个游戏把存档放在自己的文件夹里，存档会随文件夹一起进废纸篓，你仍然可以找回。

为什么它只列出游戏而不直接删除？

通过启动器卸载游戏，启动器才能正确清理，并保持你的游戏库准确。Diskshaper 会显示你没玩过的游戏，并帮你打开启动器的卸载页面。

为什么 macOS 要求访问桌面或文稿？

任何应用查看这些文件夹之前，macOS 都会先询问。Diskshaper 需要权限才能在那里找到旧安装包、大视频和重复照片。你也可以拒绝，它仍然会检查缓存和游戏。

为什么 Windows 显示 SmartScreen 警告？

代码签名证书每年都要花钱，而 Diskshaper 是免费项目。点击“更多信息”，再点“仍要运行”即可。源代码在 GitHub 上公开，可以随时查看。

不安装软件也能找重复照片吗？

可以。本网站的免费重复照片查找工具在浏览器中运行，从不上传你的照片。
