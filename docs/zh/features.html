Diskshaper 能找到的一切

三个分组，大约二十种杂物，每种都用简单的话解释，并标为“安全”或“先检查”。

给玩家给视频剪辑者给每个人工作原理

给玩家

游戏是大多数磁盘上最占空间的东西，卸载后还会留下一堆杂物。

  • 着色器缓存游戏和显卡驱动会自动重新生成的图形数据。
  • 已卸载游戏的残留Steam 和 Epic 卸载游戏后留下的文件夹。
  • 很久没玩的游戏显示上次游玩时间，并提供在启动器中卸载的按钮。
  • 空的 CrossOver 容器Mac 上里面的游戏早已删除的 Windows 环境。

给视频剪辑者

剪辑软件会悄悄存下几十 GB 的缓存、预览和代理文件。

  • Premiere、After Effects 和 Resolve 缓存媒体缓存、峰值文件、渲染缓存和代理文件。
  • 项目旁边的渲染预览Premiere 和 Final Cut 存在项目文件旁边的预览文件夹。
  • 重复的素材同一个片段复制到了三个地方。保留最早的那份。
  • 旧的导出文件六个月没动过的大型渲染文件，每个都有缩略图。

给每个人

日常杂物：只用过一次的安装包、保存了两次的同一张照片，还有旧笔记本上那个 40 GB 的备份压缩包。

  • 旧安装包下载文件夹里已经用完的 DMG、PKG、EXE 和 MSI 文件。
  • 重复照片完全相同的副本，带缩略图并排显示。
  • 被遗忘的大文件超过 1 GB 且三个月没有改动的文件。
  • 应用缓存显示每个应用的真实图标，让你知道清理的是什么。

工作原理

  1. 扫描Diskshaper 读取你的用户文件夹、应用缓存和游戏库，不会查看 macOS 或 Windows 的系统文件夹。普通电脑只需几秒钟。
  2. 分类找到的每一项都会放进一个分组，并说明它为什么在那里，以及生成它的软件会不会重新生成。
  3. 选择安全的项目已替你勾选。打开任意分组即可看到每一项，带游戏封面、应用图标和照片缩略图，你可以随意更改勾选。
  4. 移到废纸篓什么都不会被删除。清空废纸篓或回收站之前，任何东西都能放回去。
