隐私

更新于 2026 年 11 月 11 日

Diskshaper 只在你的电脑上扫描文件，从不把它们发送到任何地方。唯一的联网是每天检查一次新版本，可以关闭。本网站没有统计，也没有 Cookie。

应用会读取什么

你的用户文件夹、应用缓存和游戏库中的文件名、大小和日期，以及 Steam、Epic、Heroic 和 CrossOver 保存的游戏列表。为了查找重复文件，它会读取文件并比较内容。这些信息只保存在你电脑的内存里，关闭应用后就消失。

应用会改动什么

在你按下清理按钮之前，什么都不改。按下后，它会用系统自带的功能把你勾选的项目移到废纸篓或回收站。

网络

Diskshaper 每天向 GitHub 询问一次最新版本号。这是它唯一的联网：不会发送任何关于你、你的电脑或文件的信息，你可以在开始界面关闭它。没有统计，也没有崩溃报告。“在 Steam 中卸载”之类的按钮只会打开你电脑上的启动器。

本网站

托管在 GitHub Pages 上，GitHub 会保留标准的服务器日志。我们不添加任何统计、Cookie 或追踪器。重复照片查找工具在浏览器中运行，从不上传你的照片。

联系

有关隐私的问题：请在 GitHub 上提交 issue。
