首次启动

Mac

  1. 打开下载的 .dmg，把 Diskshaper 拖到“应用程序”。
  2. 第一次打开时，右键点击 Diskshaper，选择“打开”，再点一次“打开”。
  3. 点击“扫描”。如果 macOS 请求访问桌面、文稿或下载，请允许，这样 Diskshaper 才能找到那里的大文件。

Windows

  1. 运行安装程序。
  2. 如果出现 SmartScreen，点击“更多信息”，再点“仍要运行”。
  3. 从开始菜单打开 Diskshaper，点击“扫描”。

出现这些警告是因为 Diskshaper 没有使用付费证书签名。它免费、开源，任何人都能阅读全部代码。
